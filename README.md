# Tayson TV Launcher

Launcher Android TV em Java com banners de aplicações afixadas (Pinned Apps/Favorites).

## Compilar

O GitHub Actions compila automaticamente em cada `push`. Também é possível iniciar manualmente em **Actions → Compilar APK → Run workflow**.

O APK de depuração fica disponível no artefacto `Tayson-TV-Launcher-debug` da execução concluída.

## Requisitos

- Android Studio/Gradle para compilação local, ou GitHub Actions.
- Android 5.0 (API 21) ou superior.
- Java 17 no ambiente de compilação do GitHub Actions.
